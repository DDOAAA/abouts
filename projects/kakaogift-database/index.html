카카오톡 선물하기 프라이버시 강화 DB 설계

카카오톡 선물하기 서비스의 상품·주문·회원 흐름을 관계형 데이터베이스로 모델링하고, 비식별화와 역할 기반 접근 제어를 적용해 개인정보를 안전하게 처리하는 구조를 설계했습니다.

TEAM PROJECT
2024.06.10
DATABASE

Data Modeling

상품, 주문, 회원, 결제, 배송, 쿠폰과 후기 등 서비스의 주요 데이터를 ERD로 정의했습니다. 다대다 관계는 매핑 엔티티로 해소하고 반복 속성을 분리해 제1·제3정규화를 수행했으며, 최종 물리 모델을 MySQL 테이블과 참조 무결성 제약으로 구현했습니다.

Privacy Analysis

회원 데이터를 직접 식별자, 준식별자, 민감정보와 일반 데이터로 분류하고 ARX로 k-익명성과 l-다양성을 실험했습니다. 일반화 수준, 삭제 레코드 수, 평균 재식별 위험과 데이터 유용성을 함께 비교해 k=4, l=4를 적정 조합으로 선정했으며 최고 재식별 위험이 25%로 감소함을 확인했습니다.

Access Control

총괄책임자, 일반관리자, 내부직원과 사용자 역할을 구분해 MySQL Role과 GRANT·REVOKE 정책을 설계했습니다. 일반 사용자는 View를 통해 본인의 회원 ID와 연결된 데이터에만 접근하도록 제한하고, 업무에 필요한 최소 권한만 부여했습니다.

Data Protection

회원 비밀번호는 SHA-256 단방향 해시로 저장하도록 구성했습니다. 회원 탈퇴 시 개인정보만 연쇄 삭제하는 쿼리, 식별자 변경 시 참조 테이블을 함께 갱신하는 쿼리, 사용자의 정보 열람 요청을 위한 통합 조회 쿼리도 작성해 개인정보 생명주기 요구사항을 검증했습니다.
